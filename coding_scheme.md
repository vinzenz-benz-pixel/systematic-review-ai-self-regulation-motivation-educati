# Coding scheme
## AI-Driven Learning Analytics and Motivational Self-Regulation in Education

This coding scheme supports a theory-driven systematic review examining how AI-based learning analytics are used to support motivational self-regulation in educational settings. The review focuses on three analytical dimensions:

(a) motivational self-regulation as the target construct,
(b) AI-driven learning analytics as the operational domain, and
(c) hybrid intelligence as the distribution of regulatory roles between human actors and AI systems.

### Coding instructions

- Code the study according to the primary educational problem addressed (e.g., motivation, self-regulation, learning analytics, decision support, or collaboration).
- Distinguish between systems that merely monitor learning and systems that actively generate motivational or strategic support.
- Code both the human and AI roles separately, as well as the distribution of responsibility and decision authority.
- When a study uses generative AI, record whether it supports explanation, feedback, guidance, prediction, or decision-making.
- Flag whether the system is designed for learners, educators, or both.
