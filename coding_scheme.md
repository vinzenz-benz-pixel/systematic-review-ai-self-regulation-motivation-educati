# Coding scheme
## AI-Driven Learning Analytics in Education: Data Practices, Generative AI, Educational Decision-Making, and Human–AI Interaction

This coding scheme supports a living systematic review examining how AI-based approaches are used to collect, analyze, interpret, visualize, and communicate learner data in educational settings. It is aligned with the review's current research questions and focuses on:

(a) the use of AI-based approaches across the learning-analytics data lifecycle,
(b) the possibilities and limitations of generative-AI-supported learning analytics for educational decision-making, and
(c) the roles, responsibilities, interaction patterns, and forms of oversight involving learners, educators, and AI systems.

Self-regulated learning, motivational self-regulation, and hybrid intelligence are not standalone analytical constructs in this review. They should only be coded when they arise as an incidental educational outcome, application context, or interaction pattern within a study that otherwise meets the review criteria.

Generative AI should not be coded merely because it produces educational content; it belongs in this block only when it is connected to learner data or learning analytics as defined by the review.

### Coding instructions

- Code each study according to the review's three current analytical areas: AI-based learning-analytics practices, educational decision-making, and roles and interaction patterns.
- Map each finding to one or more research questions (RQ1, RQ2, or RQ3).
- Describe the data source, AI method, analytical purpose, output format, intended user, educational decision, and resulting action wherever the information is available.
- Distinguish between systems that collect or monitor data, systems that analyze or predict from data, systems that explain or visualize analytic results, and systems that generate recommendations or support decisions.
- Code learners, educators, and AI systems separately. Record task allocation, responsibility, decision authority, human oversight, and the possibility of reviewing or overriding AI outputs.
- When generative AI is used, record its specific function, grounding data, interaction modality, degree of autonomy, and reported opportunities, limitations, and risks.
- Do not use motivational self-regulation or hybrid intelligence as primary coding categories. If either appears in a study, record it only as contextual terminology or an incidental outcome while coding the study according to the current review scope.
